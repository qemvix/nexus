# Nexus 0.2.1 release operations

The official signed manifest is at https://raw.githubusercontent.com/qemvix/NexusApp/main/updates/stable.json. New builds include its URL and RSA public key. Daily checks are opt-in and require Network; download/install remain explicit. The 0.2.0 client needs this URL/key configured once; its existing check/download flow opens the newer installer, which updates the installed app without uninstalling.

Run scripts/build.ps1 -Publish -Integration and formatting verification. Publish the exact tested installer/portable assets in public qemvix/NexusApp using an immutable desktop-vVERSION tag. Never publish private desktop source there. Generate the signed manifest against the final installer using scripts/sign-release.ps1; commit it to NexusApp/updates/stable.json only after public download/digest verification. Keep public/assets/release.json and download page hashes aligned with those assets.

The publisher private key is DPAPI-encrypted at %LOCALAPPDATA%\NexusPublisher\update-signing-key.dpapi and is not in either repository. scripts/sign-release.ps1 uses it by default from the same Windows user. An explicit PrivateKeyFile can use an independently secured PEM instead. Preserve the encrypted key and the Windows account/profile: the encrypted file alone is not portable to a different account or PC. Never create a replacement key silently; installed clients trust the existing public key. An export/rotation needs a deliberate recovery plan.

Manifest signing authenticates update metadata and SHA-256; it is separate from Authenticode. These preview binaries remain unsigned by Windows publisher signing. No unattended installation, cloud signing service or automatic rollback is included. Portable updates create/update a per-user installed copy. The worker waits for the old process, stages the fixed install target, preserves local settings and relaunches the hub.

CI builds/tests and packages the app; signed feed publication is a separate publisher operation requiring the protected key. Public downloads and website source are NexusApp; the five-part desktop monorepo remains private nexus.
