# KeyCast

Capability: **Keyboard and Mouse**. Enable it from the module library after reviewing Permissions.

## Using it

Choose Shortcuts only for ordinary presentations, or deliberately opt into All keys. Set size, accent and display duration. The overlay shows the last key/shortcut or mouse button.

## Shortcuts

Configure a toggle shortcut on Hotkeys. Ctrl+Alt+P clears all presentation/input modules.

## Native behavior and limits

Nothing is recorded to disk. Ordinary letters/digits without modifiers are hidden in shortcuts-only mode, but other keys can appear. All-keys mode can display passwords; pause before sensitive typing. There is no password-field detection.

Disable or uninstall from Configure to release this feature's resources. Feature uninstall resets its settings; shared code remains in Nexus. See the repository test matrix for remaining hardware validation.
