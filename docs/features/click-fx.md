# ClickFX

Capability: **Mouse**. Enable it from the module library after reviewing Permissions.

## Using it

Choose Ripple, Rings or Shockwave. Adjust radius and duration. Enable the optional system sound if desired. Left clicks use your accent; right clicks use cyan.

## Shortcuts

Configure a toggle shortcut on Hotkeys.

## Native behavior and limits

Animations are capped at 30 simultaneous clicks. Reduced motion uses a stable-radius flash. No custom WAV selector or per-button animation editor is included.

Disable or uninstall from Configure to release this feature's resources. Feature uninstall resets its settings; shared code remains in Nexus. See the repository test matrix for remaining hardware validation.
