# Float

Capability: **None; optional Network**. Enable it from the module library after reviewing Permissions.

## Using it

Enable Float for CPU, physical RAM, clock and Windows/core information. Drag the standard window to position it. Use media buttons for previous/play/next. Grant network access and enter latitude,longitude to fetch weather.

## Shortcuts

Configure a toggle shortcut on Hotkeys. Close the floating window and toggle the feature to reopen.

## Native behavior and limits

Weather uses Open-Meteo, fetched once on enable with an 8-second timeout. Disable and enable to refresh. No geolocation permission is requested. Media controls send standard media keys; they do not read track titles.

Disable or uninstall from Configure to release this feature's resources. Feature uninstall resets its settings; shared code remains in Nexus. See the repository test matrix for remaining hardware validation.
