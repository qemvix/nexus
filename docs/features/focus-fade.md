# FocusFade

Capability: **Windows**. Enable it from the module library after reviewing Permissions.

## Using it

Enable and select a dimming amount, outline width and accent. The active external window stays clear while its surroundings dim.

## Shortcuts

Configure a toggle shortcut on Hotkeys.

## Native behavior and limits

Overlays are non-activating and click-through. The Nexus hub is excluded so configuration remains visible. This release does not minimize/hide other windows, provide per-app exclusions or interpolate focus changes.

Disable or uninstall from Configure to release this feature's resources. Feature uninstall resets its settings; shared code remains in Nexus. See the repository test matrix for remaining hardware validation.
