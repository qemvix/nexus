# Cursor Aura

Capability: **Mouse**. Enable it from the module library after reviewing Permissions.

## Using it

Choose glow, soft halo, trail, particles or spotlight, then tune radius, opacity and accent. Pair it with ClickFX for click animation.

## Shortcuts

No fixed action shortcut; add a toggle shortcut on Hotkeys.

## Native behavior and limits

Pointer activity feeds one shared mouse hook. The overlay is click-through. Blur is a soft glow treatment rather than modification of the Windows cursor bitmap.

Disable or uninstall from Configure to release this feature's resources. Feature uninstall resets its settings; shared code remains in Nexus. See the repository test matrix for remaining hardware validation.
