# QuickDock

Capability: **None**. Enable it from the module library after reviewing Permissions.

## Using it

Use the floating dock for mute, volume up/down and play/pause. Buttons open the native Windows sound mixer, displays/brightness, Wi-Fi, Bluetooth, accessibility and power settings.

## Shortcuts

Ctrl+Alt+Q opens the dock. Configure a module toggle shortcut separately.

## Native behavior and limits

Hardware availability varies. Device buttons delegate to Windows settings rather than claiming direct control of unsupported hardware. Closing the dock leaves its shortcut registered until the module is disabled.

Disable or uninstall from Configure to release this feature's resources. Feature uninstall resets its settings; shared code remains in Nexus. See the repository test matrix for remaining hardware validation.
