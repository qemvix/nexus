# Media assets

`nexus-logo.svg` is the original vector diamond/orbit mark. `nexus-dashboard.png` and the other Nexus screen PNGs are rendered from the actual WPF app using its isolated smoke mode, not web mockups. They are generated/captured on the build host; they are not photographs of every utility operating across arbitrary third-party applications.
