# nexus-cursor

Cursor Aura, ClickFX, ScrollFlow and Cursor Lens for the Nexus host. ScrollFlow directly hosts the native engine adapted from the owner's [qemvix/Glide](https://github.com/qemvix/Glide) source; it does not stack Nexus's previous smoothing timer on top.

See [Glide integration](../../docs/GLIDE_INTEGRATION.md) for source provenance, adaptations and validation.
